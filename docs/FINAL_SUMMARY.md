## Реализованные функции

- Консольное меню с пунктами 0 по 5.
- Просмотр всех записей в табличном виде.
- Добавление записи с автоматическим номером в формате INV0001.
- Поиск по номеру и по кабинету с сообщением «Не найдено».
- Изменение состояния и кабинета.
- Удаление с подтверждением и возможностью отмены.
- Сохранение в data/inventory.json и загрузка при старте.
- Безопасная обработка отсутствующего и повреждённого файла данных.

## Не реализовано и почему

- Графический интерфейс: по условию проекта требуется только CLI.
- Сложные фильтры и сортировки: выходят за рамки базового CRUD, отмечены в ограничениях.
- Многопользовательский режим: не предусмотрен условиями проекта.
