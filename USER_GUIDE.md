# Инструкция пользователя: CollegeAsset

Приложение для учёта компьютерного оборудования колледжа. Работает в консоли, не требует установки базы данных.

## 1. Запуск

Откройте терминал в папке с файлом main.py и выполните:

- Windows: python main.py
- Linux, macOS: python3 main.py

После запуска появится главное меню с пунктами 0 по 5.

## 2. Просмотр оборудования

Нажмите 1 и Enter. Программа выведет таблицу со всеми записями. Если записей нет, появится сообщение «Список пуст».

## 3. Добавление записи

1. Нажмите 2 и Enter.
2. Введите тип оборудования (например, ПК, монитор, принтер).
3. Введите наименование (например, «Системный блок Lenovo»).
4. Введите кабинет (например, 305).
5. Введите состояние: исправно, требует ремонта или списано.
6. Программа присвоит инвентарный номер автоматически и сохранит запись.

Если оставить поле пустым, программа выведет сообщение об ошибке и попросит повторить ввод. Программа не завершится аварийно.

## 4. Поиск

1. Нажмите 3 и Enter.
2. Введите инвентарный номер (например, INV0003) или кабинет (например, 305).
3. Программа выведет все совпадающие записи.
4. Если ничего не найдено, появится сообщение «Не найдено».

## 5. Изменение записи

1. Нажмите 4 и Enter.
2. Введите инвентарный номер нужной записи.
3. Выберите, что изменить: состояние или кабинет.
4. Введите новое значение.
5. Программа сохранит изменение в файл.

Если номер не найден, программа сообщит об этом и вернёт в меню.

## 6. Удаление записи

1. Нажмите 5 и Enter.
2. Введите инвентарный номер.
3. Программа запросит подтверждение. Введите y для удаления или n для отмены.
4. При подтверждении запись удаляется и файл обновляется. При отказе запись остаётся.

## 7. Выход

Нажмите 0 и Enter. Все изменения к этому моменту уже сохранены в файле data/inventory.json.

## 8. Где хранятся данные

Файл data/inventory.json в папке проекта. Его можно открыть текстовым редактором для просмотра. Не рекомендуется редактировать вручную: можно нарушить структуру данных.

## 9. Типовые проблемы

- Программа не запускается по команде python: используйте python3 (Linux, macOS) или py (Windows).
- Появилось сообщение о повреждённом файле данных: программа создаст пустой список. Восстановите файл из резервной копии или из репозитория.
- Тесты не запускаются: установите pytest командой pip install pytest.
