# CollegeAsset: Система учёта ИТ-оборудования колледжа

Консольное приложение (CLI) на Python для автоматизации инвентаризации и контроля компьютерной техники в учебных аудиториях колледжа.

Репозиторий: https://github.com/Daammooyy/CollegeAsset/
Документация проекта (wiki): https://github.com/Daammooyy/CollegeAsset/wiki

## Назначение проекта

В колледже теряется информация об оборудовании компьютерных классов: нет единого списка техники, непонятно, где находится конкретный компьютер, кто за него отвечает и в каком он состоянии. Приложение решает эту задачу: хранит единый реестр оборудования, позволяет быстро находить нужную запись и не теряет данные между запусками.

## Возможности

- Просмотр всех инвентарных записей в виде таблицы.
- Добавление новой записи с автоматической генерацией инвентарного номера (формат INV0001).
- Поиск по инвентарному номеру и по кабинету.
- Изменение состояния и кабинета существующей записи.
- Удаление записи с обязательным подтверждением.
- Автоматическое сохранение данных в JSON-файл и загрузка при старте.
- Безопасная обработка отсутствующего или повреждённого файла данных.

## Структура проекта

```text
CollegeAsset/
  main.py               меню и взаимодействие с пользователем
  inventory.py          логика работы со списком оборудования (CRUD, поиск)

  data/

  tests/

```

## Требования

- Python 3.11 или новее.
- Git (для клонирования репозитория).
- pytest (для запуска тестов).
- Docker (необязательно, для запуска в контейнере).

## Установка и запуск

### Windows

1. Откройте терминал: нажмите Win + R, введите cmd и нажмите Enter (или откройте PowerShell).
2. Скачайте проект и перейдите в папку с программой:

```bash
git clone https://github.com/Daammooyy/CollegeAsset/
cd CollegeAsset\CollegeAsset
```

3. Запустите программу:

```bash
python main.py
```

Если команда python не сработает, используйте py main.py.

### Linux (Ubuntu, Debian и другие)

1. Откройте терминал: нажмите Ctrl + Alt + T или найдите «Терминал» в меню приложений.
2. Скачайте проект и перейдите в папку с программой:

```bash
git clone https://github.com/Daammooyy/CollegeAsset/
cd CollegeAsset/CollegeAsset
```

3. Запустите программу:

```bash
python3 main.py
```

Если git или python3 не установлены:

```bash
sudo apt update && sudo apt install python3 git -y
```

### macOS

1. Откройте терминал: нажмите Cmd + Пробел, введите Terminal и нажмите Enter.
2. Скачайте проект и перейдите в папку с программой:

```bash
git clone https://github.com/Daammooyy/CollegeAsset/
cd CollegeAsset/CollegeAsset
```

3. Запустите программу:

```bash
python3 main.py
```

Если система предложит установить инструменты разработчика командной строки для работы Git, нажмите «Установить».

### Альтернативный запуск без Git (любая ОС)

1. На странице репозитория нажмите зелёную кнопку Code, затем Download ZIP.
2. Распакуйте архив и откройте внутреннюю папку CollegeAsset, где находится файл main.py.
3. Откройте терминал в этой папке и выполните python main.py (Windows) или python3 main.py (Linux, macOS).

### Запуск через Docker (при наличии)

```bash
docker build -t collegeasset .
docker run -it collegeasset
```

## Команды меню

- 1: показать всё оборудование.
- 2: добавить новую запись.
- 3: найти оборудование.
- 4: изменить запись.
- 5: удалить запись.
- 0: выход.

## Пользовательские сценарии

**Сценарий 1. Просмотр списка.**
Пользователь запускает программу и выбирает пункт 1. На экран выводится таблица со всеми инвентарными записями: номер, тип, наименование, кабинет, состояние. Если список пуст, выводится сообщение «Список пуст».

**Сценарий 2. Добавление записи.**
Пользователь выбирает пункт 2. Программа запрашивает тип, наименование, кабинет и состояние. Инвентарный номер генерируется автоматически. Если введены пустые поля, выводится сообщение об ошибке и запись не создаётся.

**Сценарий 3. Поиск.**
Пользователь выбирает пункт 3 и вводит инвентарный номер или кабинет. Программа выводит все совпадающие записи. Если ничего не найдено, выводится сообщение «Не найдено».

**Сценарий 4. Изменение.**
Пользователь выбирает пункт 4 и вводит инвентарный номер. Программа предлагает изменить состояние или кабинет. После ввода новых данных запись обновляется и сохраняется в файл.

**Сценарий 5. Удаление.**
Пользователь выбирает пункт 5 и вводит инвентарный номер. Программа запрашивает подтверждение. При отказе запись остаётся, при подтверждении запись удаляется и файл JSON обновляется.

**Сценарий 6. Сохранение между запусками.**
Все изменения автоматически сохраняются в data/inventory.json. При следующем запуске данные загружаются из файла. Если файл отсутствует или повреждён, программа создаёт пустой список и продолжает работу без сбоев.

## Хранение данных

Данные хранятся в файле data/inventory.json в виде массива объектов. Минимальная запись содержит:

- inventory_number: уникальный инвентарный номер;
- type: тип оборудования (ПК, монитор, принтер и другие);
- name: наименование;
- room: кабинет;
- status: состояние (исправно, требует ремонта, списано).

## Тестирование

Запуск автотестов:

```bash
python -m pytest
```

Тесты проверяют добавление записи, поиск по номеру и кабинету, изменение, удаление, а также чтение и запись JSON-файла, обработку отсутствующего и повреждённого файла.

## Архитектура

Приложение разделено на три модуля:

- main.py отвечает за меню и ввод пользователя;
- inventory.py содержит функции CRUD и поиска;
- storage.py отвечает за чтение и запись JSON.

Такое разделение позволяет тестировать логику независимо от консольного интерфейса.

## Известные ограничения

- Приложение работает только в консольном режиме, графический интерфейс отсутствует.
- Поиск выполняется по вхождению подстроки, сложные фильтры и сортировки не поддерживаются.
- Одновременная работа нескольких пользователей с одним файлом JSON не поддерживается.
- Автоматическая генерация номеров не гарантирует уникальность при ручном редактировании файла data/inventory.json.
- Dockerfile не является обязательным и может отсутствовать на учебных компьютерах.
