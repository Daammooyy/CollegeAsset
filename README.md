# CollegeAsset - Система учета ИТ-оборудования колледжа

Веб-приложение для автоматизации инвентаризации, контроля статусов и отслеживания перемещений компьютерной техники и комплектующих по учебным аудиториям колледжа. Проект разработан в рамках 6-дневного учебного интенсива.

## Проблема и решение
**Проблема:** В колледже теряется информация об оборудовании из-за ручного учета в Excel и отсутствия фиксации перемещений между кабинетами.
**Решение:** Единая база данных ИТ-активов с быстрой фильтрацией по аудиториям, отслеживанием статусов ремонта и логированием истории перемещений.

## Функционал MVP (Что реализуется за 6 дней)
* **База данных ИТ-активов:** Учет ПК, мониторов и комплектующих (модель, серийный номер, характеристики).
* **Контроль статусов:** Мониторинг состояния техники (Исправно, Требует ремонт, Списано).
* **Локации:** Привязка оборудования к конкретным кабинетам и материально ответственным лицам.
* **Фильтрация и поиск:** Быстрый поиск железа по инвентарному номеру или номеру аудитории.
* **Логирование:** Просмотр истории изменений каждого устройства.

## Инструкция по развертыванию на Linux

### 1. Клонирование репозитория
```bash
git clone https://github.com/Daammooyy/collegeassets.git
cd CollegeAsset
```

### 2. Настройка Python
```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 main.py
```

## Инструкция по развертыванию на Windows

### 1. Клонирование репозитория
```cmd
git clone https://github.com
cd collegeassets
```

### 2. Настройка Python
```cmd
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
