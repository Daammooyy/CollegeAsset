# CollegeAsset — Система учёта ИТ-оборудования колледжа

Консольное приложение (CLI) на Python для автоматизации инвентаризации и контроля компьютерной техники в учебных аудиториях колледжа.

## Основной функционал и архитектура

- **Возможности:** Просмотр инвентаря, добавление новых записей с автогенерацией номеров (`INV0001`), многословный поиск по всем полям, изменение статуса или кабинета и безопасное удаление с подтверждением.
- **Хранение данных:** Автоматическое сохранение в JSON-файл (`CollegeAsset/data/inventory.json`). При первом запуске или повреждении файла программа создаёт пустой список и продолжает работу без сбоев.
- **Структура проекта:**
  - `main.py` — консольное меню и взаимодействие с пользователем;
  - `inventory.py` — логика работы со списком оборудования;
  - `storage.py` — чтение и запись JSON-файла;
  - `data/inventory.json` — база данных оборудования;
  - `tests/` — автоматические тесты (`pytest`).

## Установка и запуск (пошаговая инструкция)

Для работы потребуется установленный **Python 3.11 или новее** и **Git**.

### Для Windows

1. **Откройте терминал:** нажмите `Win + R`, введите `cmd` и нажмите `Enter` (или откройте PowerShell).
2. **Скачайте проект и перейдите в папку с программой:**
   ```bash
   git clone https://github.com/Daammooyy/CollegeAsset/
   cd CollegeAsset\CollegeAsset
   ```
3. **Запустите программу:**
   ```bash
   python main.py
   ```
   *(Если команда `python` не сработает, попробуйте `py main.py`).*

### Для Linux (Ubuntu, Debian и др.)

1. **Откройте терминал:** нажмите `Ctrl + Alt + T` или найдите «Терминал» в меню приложений.
2. **Скачайте проект и перейдите в папку с программой:**
   ```bash
   git clone https://github.com
   cd CollegeAsset/CollegeAsset
   ```
3. **Запустите программу:**
   ```bash
   python3 main.py
   ```
   *(Если `git` или `python3` не установлены, выполните: `sudo apt update && sudo apt install python3 git -y`).*

### Для macOS

1. **Откройте терминал:** нажмите `Cmd + Пробел`, введите `Terminal` и нажмите `Enter`.
2. **Скачайте проект и перейдите в папку с программой:**
   ```bash
   git https://github.com/Daammooyy/CollegeAsset/
   cd CollegeAsset/CollegeAsset
   ```
3. **Запустите программу:**
   ```bash
   python3 main.py
   ```
   *(Если при первом запуске система предложит установить «Инструменты разработчика командной строки» для работы Git — нажмите «Установить»).*

### Альтернативный запуск без Git (для любой ОС)
1. На странице репозитория вверху нажмите зелёную кнопку **Code** → **Download ZIP**.
2. Распакуйте архив и откройте внутреннюю папку `CollegeAsset` (где находится файл `main.py`).
3. Откройте терминал в этой папке и выполните `python main.py` (для Windows) или `python3 main.py` (для Linux/macOS).

## Краткая инструкция пользователя

Управление осуществляется цифрами в меню:
- `1` — показать всё оборудование;
- `2` — добавить новую запись (номер кабинета вводится только цифрами);
- `3` — поиск по инвентарному номеру, кабинету, названию или ответственному;
- `4` — изменить статус (`исправно` / `требует ремонта` / `списано`) или кабинет;
- `5` — удалить запись по порядковому номеру (требуется подтверждение `д/н`);
- `0` — выход из программы.

Для отмены изменения или удаления введите слово `stop`.

## Запуск автотестов

Для проверки работоспособности кода выполните из папки `CollegeAsset` команду:
```bash
python -m pytest
```
*(Для Linux/macOS: `python3 -m pytest`).*
